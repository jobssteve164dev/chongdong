# 代理链状态显示功能说明

## 功能概述

代理链状态显示用于呈现核心进程和链路管理器实际返回的状态。它不根据用户点击或本地缓存推断“已连接”。

- 实时显示代理链中每个节点的连接状态
- 显示每个节点的流量统计信息
- 提供安全的IP地址检测功能
- 支持代理链的链路结构可视化

## 主要特性

### 1. 代理链状态监控

- **整体状态显示**：显示代理链的运行状态（运行中/已停止/错误）
- **节点状态列表**：显示每个节点的详细状态信息
- **流量统计**：实时显示上传、下载流量和连接数
- **运行时间**：显示代理链的运行时长

### 2. IP地址检测功能

- **出口观测**：通过明确的本地 SOCKS 入口请求外部 IP 服务；入口不可用时检测失败
- **地理位置信息**：显示IP地址对应的地理位置信息
- **隐私保护**：提供IP地址隐藏/显示功能
- **多API支持**：使用多个IP检测API提高成功率

### 3. 用户界面

- **响应式设计**：适配不同屏幕尺寸
- **实时刷新**：自动更新状态信息
- **手动刷新**：支持手动刷新状态
- **错误提示**：清晰的错误信息显示

## 使用方法

### 1. 在仪表盘查看代理链状态

当使用代理链模式时，仪表盘会自动显示代理链状态信息：

1. 启动代理链后，仪表盘的连接状态卡片会显示代理链信息
2. 在连接状态卡片下方会显示详细的代理链状态组件
3. 可以查看每个节点的连接状态和流量统计

### 2. 在代理管理页面查看

在代理管理页面中：

1. 选择并启动一个代理链
2. 页面下方会自动显示代理链状态组件
3. 可以查看详细的节点信息和状态

### 3. IP地址检测

要检测代理链中每个节点的IP地址：

1. 在代理链状态组件中，找到"节点IP地址检测"部分
2. 点击"检测IP"按钮开始检测
3. 检测完成后会显示每个节点的IP地址和地理位置信息
4. 使用"显示IP"/"隐藏IP"按钮控制IP地址的显示

## 隐私保护

### 1. IP地址保护

- 默认情况下，IP地址会被隐藏显示为 `***.***.***.***`
- 用户需要主动点击"显示IP"按钮才能查看真实IP地址
- 检测功能会显示隐私提醒，提醒用户注意安全

### 2. 检测方法

- 使用 SOCKS5 本地入口进行 IP 检测，TLS 证书校验保持开启
- 检测请求不会为了生成“通过”结果而回退到主进程直连
- 通过多个API服务提高检测成功率

### 3. 缓存机制

- IP检测结果会被缓存5分钟，避免频繁检测
- 用户可以手动清理缓存
- 缓存信息不会持久化存储

## 技术实现

### 1. 后端架构

- **ChainStatusManager**：代理链状态管理器，负责收集和提供状态信息
- **ProxyChainMiddlewareManager**：代理链中间件管理器，集成状态管理
- **IPC处理程序**：提供前后端通信接口

### 2. 前端组件

- **ChainStatusDisplay**：代理链状态显示组件
- **ChainIPDetector**：IP检测工具类
- **类型定义**：完整的TypeScript类型支持

### 3. 数据流

```
用户操作 → 前端组件 → IPC通信 → 后端管理器 → 代理链中间件 → 状态更新 → 前端显示
```

## 故障排除

### 1. 状态显示异常

如果代理链状态显示异常：

1. 检查代理链是否正在运行
2. 尝试手动刷新状态
3. 查看控制台错误信息
4. 重启代理链服务

### 2. IP检测失败

如果IP检测失败：

1. 检查代理链是否正常工作
2. 确认网络连接正常
3. 尝试使用不同的IP检测API
4. 检查防火墙设置

### 3. 性能问题

如果遇到性能问题：

1. 减少状态刷新频率
2. 清理IP检测缓存
3. 关闭不必要的IP检测功能
4. 检查系统资源使用情况

## 安全建议

### 1. 使用环境

- 仅在可信的网络环境中使用IP检测功能
- 避免在公共网络或不安全的网络中使用
- 定期检查代理链的配置和日志

### 2. 隐私保护

- 不要在不必要的情况下显示真实IP地址
- 定期清理检测缓存
- 注意保护代理链的配置信息

### 3. 网络安全

- 确保代理链的配置正确且安全
- 使用高匿名代理服务器
- 定期更新代理服务器配置
