# 地理位置防护使用说明

## 概述

虫洞应用现在提供了全面的地理位置泄露防护功能，可以有效防止应用通过多种途径获取您的真实地理位置信息。

## 防护机制

### 1. DNS防护
- **强制代理DNS**: 所有DNS查询都通过代理服务器
- **阻止直接DNS**: 防止直接DNS查询泄露真实位置
- **DNS over HTTPS**: 使用加密的DNS查询

### 2. IPv6防护
- **禁用IPv6**: 完全禁用IPv6连接
- **阻止IPv6泄露**: 防止IPv6地址泄露真实位置

### 3. WebRTC防护
- **禁用WebRTC**: 完全禁用WebRTC功能
- **阻止STUN服务器**: 防止WebRTC通过STUN服务器获取真实IP

### 4. 浏览器指纹防护
- **随机化User-Agent**: 随机化浏览器标识
- **隐藏时区信息**: 隐藏系统时区信息
- **隐藏语言设置**: 隐藏系统语言信息
- **隐藏屏幕分辨率**: 隐藏屏幕分辨率信息
- **隐藏Canvas指纹**: 防止Canvas指纹识别

### 5. 网络接口防护
- **隐藏MAC地址**: 隐藏网络接口MAC地址
- **隐藏网络接口**: 隐藏网络接口信息
- **随机化网络信息**: 随机化网络相关信息

### 6. HTTP/2.0特定防护
- **连接隔离**: 为敏感域名使用独立连接
- **头部表清理**: 定期清理HPACK动态表
- **时序混淆**: 通过批处理和随机延迟混淆时序
- **协议降级**: 支持强制使用HTTP/1.1协议

### 7. 代理链验证
- **验证代理链**: 验证代理链是否正常工作
- **监控代理健康**: 实时监控代理服务器状态
- **自动切换**: 代理失败时自动切换

## 使用方法

### 1. 启用防护功能

在应用设置中启用以下选项：

```typescript
// 在设置中启用所有防护功能
const settings = {
  // DNS防护
  enableDnsLeakProtection: true,
  dnsLeakProtectionMode: 'strict',
  
  // IPv6防护
  enableIpv6LeakProtection: true,
  ipv6LeakProtectionMode: 'strict',
  
  // WebRTC防护
  enableWebRTCLeakProtection: true,
  webRTCLeakProtectionMode: 'strict',
  
  // HTTP头部防护
  enableHttpHeaderProtection: true,
  httpHeaderProtectionMode: 'strict',
  
  // 时序泄露防护
  enableTimingLeakProtection: true,
  timingLeakProtectionMode: 'strict',
  
  // MAC地址防护
  enableMacAddressProtection: true,
  macAddressProtectionMode: 'strict',
  
  // HTTP/2.0防护
  enableHttp2Protection: true,
  http2ProtectionMode: 'strict',
  http2ConnectionIsolation: true,
  http2HeaderTableCleanup: true,
  http2TimingObfuscation: true,
  http2ForceHttp1: false, // 根据需要设置
  http2SensitiveDomains: [
    'google.com',
    'facebook.com',
    'twitter.com',
    'instagram.com',
    'youtube.com',
    'amazon.com',
    'microsoft.com',
    'apple.com'
  ]
};
```

## 测试项目

地理位置泄露测试包括以下项目：

1. **IP地址泄露测试**: 检测真实IP地址是否泄露
2. **DNS泄露测试**: 检测DNS查询是否泄露真实位置
3. **WebRTC泄露测试**: 检测WebRTC是否泄露真实IP
4. **IPv6泄露测试**: 检测IPv6地址是否泄露
5. **浏览器指纹测试**: 检测浏览器指纹是否暴露位置信息
6. **时区泄露测试**: 检测时区信息是否泄露
7. **语言泄露测试**: 检测语言设置是否泄露位置
8. **代理链测试**: 检测代理链是否正常工作

## 常见问题

### Q: 为什么应用仍然能知道我的地理位置？

A: 可能的原因包括：
1. 防护功能没有正确启用
2. 代理配置有问题，流量没有通过代理
3. 某些防护措施只是检测功能，没有实际防护
4. 存在其他未覆盖的泄露途径

### Q: 如何验证防护效果？

A: 建议：
1. 定期运行地理位置泄露测试
2. 使用在线IP检测服务验证
3. 检查代理链是否正常工作
4. 监控防护状态和日志

### Q: 防护功能会影响网络性能吗？

A: 可能会有轻微影响：
1. 连接隔离会增加连接数
2. 时序混淆会增加延迟
3. 头部清理会增加处理时间
4. 建议在性能和隐私之间找到平衡

## 最佳实践

1. **定期测试**: 建议每周运行一次地理位置泄露测试
2. **监控状态**: 定期检查防护状态和代理健康状态
3. **更新配置**: 根据测试结果调整防护配置
4. **备份设置**: 保存有效的防护配置
5. **日志监控**: 关注防护日志，及时发现异常
