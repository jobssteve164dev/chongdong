## 2. 核心实现 (Core Implementation)

### a. 方法论/设计思路
为了提升界面的美观度和和谐性，采用隐藏滚动条但保持滚动功能的方案。通过CSS的多种属性来确保在不同浏览器中都能正确隐藏滚动条，同时保持内容的可滚动性。

### b. 主要变更文件 (Key Changed Files)
*   `MODIFIED`: `src/renderer/App.css` - 隐藏content-wrapper和app-content的滚动条
*   `MODIFIED`: `src/renderer/index.css` - 隐藏全局滚动条样式

### c. 关键代码片段
**隐藏content-wrapper滚动条**:
```css
.content-wrapper {
  max-width: 1200px;
  margin: 0 auto;
  height: 100%;
  overflow-y: auto;
  overflow-x: hidden;
  /* 隐藏滚动条但保持滚动功能 */
  scrollbar-width: none; /* Firefox */
  -ms-overflow-style: none; /* IE and Edge */
}

.content-wrapper::-webkit-scrollbar {
  display: none; /* Chrome, Safari and Opera */
}
```

**隐藏全局滚动条**:
```css
/* index.css */
::-webkit-scrollbar {
  display: none;
}

* {
  scrollbar-width: none; /* Firefox */
  -ms-overflow-style: none; /* IE and Edge */
}
```
