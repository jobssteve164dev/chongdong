## 2. 核心实现 (Core Implementation)

### a. 方法论/设计思路

**问题根因分析**：
1. **协议不兼容**：vmess -> trojan 的代理链不被sing-box 1.8.0原生支持
2. **证书验证问题**：代理链中的节点没有正确配置TLS设置
3. **架构限制**：依赖sing-box本身的代理链能力，无法处理混合协议场景

**解决方案**：
采用了**代理链中间件架构**，核心思想是为每个节点创建独立的sing-box实例，通过中间件在节点间转发流量，而不是依赖sing-box本身的代理链能力。

**架构设计**：
```
客户端 → 流量路由器(7895) → 协议适配器1(7896) → 协议适配器2(7897) → 互联网
```
