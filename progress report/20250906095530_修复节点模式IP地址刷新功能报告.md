## 2. 核心实现 (Core Implementation)

### a. 方法论/设计思路
通过分析IP地址检测的完整流程，发现了端口配置不匹配的问题：
1. Dashboard中的IP检测使用HTTP端口（7897）
2. 主进程IPC处理器期望SOCKS端口（7896）
3. 端口不匹配导致SOCKS5连接失败

### b. 主要变更文件 (Key Changed Files)
*   `MODIFIED`: `src/renderer/pages/Dashboard.tsx` - 修复IP地址检测的端口配置

### c. 关键代码片段 (Optional but Recommended)

**修复前的问题代码**：
```typescript
// 使用HTTP端口，但主进程IPC处理器期望SOCKS端口
const proxyPort = settings?.proxyPort || 7897; // HTTP端口
const proxyUrl = `http://127.0.0.1:${proxyPort}`;
```

**修复后的正确代码**：
```typescript
// 使用SOCKS端口，与主进程IPC处理器保持一致
const socksPort = settings?.socksPort || 7896; // SOCKS端口
const proxyUrl = `http://127.0.0.1:${socksPort}`;
```
