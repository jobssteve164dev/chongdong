### a. 方法论/设计思路

### c. 关键代码片段 (Key Code Snippets)

**示例: 自定义服务器管理器核心方法**
```typescript
// src/renderer/utils/customServerManager.ts
export class CustomServerManager {
  public addCustomServer(serverData: Omit<ProxyServer, 'id' | 'isCustom'>): ProxyServer {
    const server: ProxyServer = {
      ...serverData,
      id: uuidv4(),
      isCustom: true,
    };
    this.customServers.push(server);
    this.saveCustomServers();
    return server;
  }
}
```

**示例: 节点管理页面集成自定义服务器**
```typescript
// src/renderer/pages/NodeManagement.tsx
// 添加自定义服务器
const customServers = customServerManager.getCustomServers();
customServers.forEach(server => {
  nodesWithSubscription.push({
    ...server,
    subscriptionName: '自定义服务器',
    subscriptionId: 'custom',
  });
});
```
