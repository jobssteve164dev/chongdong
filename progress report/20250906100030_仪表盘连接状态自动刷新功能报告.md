## 2. 核心实现 (Core Implementation)

### a. 方法论/设计思路
通过分析现有的状态广播机制，发现代理管理页面启动代理后没有通过主进程广播状态变化，导致Dashboard无法自动刷新。解决方案是：
1. 在代理管理页面启动代理后，通过IPC调用主进程广播状态变化
2. 优化App.tsx中的状态监听逻辑，支持节点模式和代理链模式的状态更新
3. 确保状态变化能够正确传递到Dashboard组件

### b. 主要变更文件 (Key Changed Files)
*   `MODIFIED`: `src/renderer/pages/ProxyManagement.tsx` - 添加状态广播逻辑
*   `MODIFIED`: `src/main/index.ts` - 添加代理状态广播IPC处理器
*   `MODIFIED`: `src/renderer/App.tsx` - 优化状态监听逻辑

### c. 关键代码片段 (Optional but Recommended)

**代理管理页面状态广播**：
```typescript
// 启动节点代理后广播状态
await window.electron.ipcRenderer.invoke('proxy:broadcastStatus', {
  running: true,
  source: 'proxy-management-node',
  nodeId: selectedNode.id,
  nodeName: selectedNode.name
});

// 启动代理链后广播状态
await window.electron.ipcRenderer.invoke('proxy:broadcastStatus', {
  running: true,
  source: 'proxy-management-chain',
  chainId: chain.id,
  chainName: chain.name,
  chainType: chain.type
});
```

**主进程IPC处理器**：
```typescript
ipcMain.handle('proxy:broadcastStatus', async (_, payload) => {
  try {
    console.log('收到代理状态广播请求:', payload);
    broadcastProxyStatus(payload.running, payload);
    return { success: true };
  } catch (error) {
    console.error('Failed to broadcast proxy status:', error);
    return { success: false, error: error instanceof Error ? error.message : 'Unknown error' };
  }
});
```

**优化的状态监听逻辑**：
```typescript
// 监听主进程广播的状态变化
const offStatusChanged = window.electron.ipcRenderer.on('proxy:statusChanged', async (payload: any) => {
  if (payload?.running) {
    if (payload?.chainId) {
      // 代理链模式
      setCurrentProxyChain(chainConfig);
      setCurrentProxyNode(null);
    } else if (payload?.nodeId) {
      // 节点模式
      setCurrentProxyNode(node);
      setCurrentProxyChain(null);
    }
  } else {
    // 代理停止，清空所有信息
    setCurrentProxyChain(null);
    setCurrentProxyNode(null);
  }
});
```
